Milestones

ft_transcendence is an AI-driven platform for learning a foreign language. A short adaptive test places each learner at a CEFR level, and a roadmap then gives them lessons sized to their daily goal. This page summarises the milestones in progress: what each one delivers, how its issues depend on each other, and the data model behind it.

1 · Onboarding and Evaluation 2 · Course Roadmap and Lessons 3 · Real-time, social and defence
Milestone 1

Onboarding and Evaluation

A new learner chooses a language and a daily goal of 10, 30 or 60 minutes, then takes an adaptive placement exam or sets their level themselves. The exam runs a binary search from B1 over 270 authored questions, with the server owning the clock. The learner then lands on the course home, and can switch between courses or add another language. All issues are closed: the placement page and its result screen (#50) landed with PR #104.

Milestone 2 · due 1 December 2026

Course Roadmap and Lessons

The course page and the lessons: the daily goal page, the all lessons page with search, the four lesson pages (grammar, vocabulary, functions, reading), a discussion with the LLM tutor before each exam, results, the streak, level completion and gamification. Replanned in #137: a lesson follows the prototype's model and is written offline with Claude Code. Every outline row is seeded (3,990); a lesson is ready when its files exist, the first 12 of each language and level, 216 in all, and the others show as "Coming soon". The server keeps each attempt, checks every answer and owns the exam timer. On main: the roadmap API (#79 to #82), gamification rules (#94), the seed from the outlines (#134) and the lesson schemas and validators of the prototype (#135, PR #142). In review: demo learners (#85, PR #143), the German and English validators (#136, PR #162) and the wording fixes (#153, PR #164).

Milestone 3 · due 1 December 2026

Real-time, social and defence

The social half of the app and the defence. Friends, public profiles, online status and direct messages, live over WebSockets: the real-time major, the user interaction major and the missing half of standard user management, 6 of the 19 points. Then what the evaluation checks beyond features: two more browsers, the README and a rehearsed defence. It runs in parallel with Milestone 2. One WebSocket connection per tab, in a user:<id> room; the lesson discussion streams over SSE (Milestone 2), not over the socket. Not built: notifications. In work: the gateway (#154), Firefox and WebKit (#159, PR #165) and the signup rate limit (#34).
