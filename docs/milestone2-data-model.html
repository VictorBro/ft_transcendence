Relations between formats
How one shape turns into another as data moves through the layers. Block color = the group it belongs to.

LessonDraftLessonEntryThe generator's title, summary and brief are merged into the outline classification. LessonOutlineEntryLessonEntryKeeps id, kind, topic, theme; drops workingTitle and intent. lesson-files.spec enforces the match. LessonFileseedLessonsParsed with LessonFileSchema; bad files and duplicate ids fail by name. seedLessonsLessonAdds lang and level from the file, position from the array index. Upserts only changes. LessonBriefLesson.briefValidated by Zod on the way in, stored as untyped Json, never selected by the read routes. EnumsPrisma enumsLESSON_KINDS and THEMES mirror LessonKind and Theme; kept in sync by hand. Lesson + LessonResultLessonCardMapped to rule types in #80, then to a card; no result means status todo and nulls. LessonCardToday, LessonPageBoth views are containers of cards. LessonQueryLessonPageFilters, sort, group and page drive the in-memory search; total follows filters, levelTotal doesn't. UserLevel streak colsToday.streakstreak, bestStreak and lastGoalDay become current, best and today via currentStreak. FinishLessonLessonResult, UserLevelUpserts the result (best score kept) and may write the streak. LessonResult, UserLevelFinishResultcountedToday and doneCount come from that day's rows; goalJustMet is true only when this call wrote the streak.
