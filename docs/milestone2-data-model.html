Zod schemas, enums, constants and helpers imported by the generator, seed, API and web. No database access, so it landed first and unblocks everything else. Every text field uses one rule: 1 to max characters, already trimmed (an untrimmed string is rejected, never trimmed silently), and no line breaks or invisible characters.

Relations between formats
How one shape turns into another as data moves through the layers. Block color = the group it belongs to.
Enums + constantsShared contractContent filesCI + seedDatabaseAPI
LessonDraftLessonEntryThe generator's title, summary and brief are merged into the outline classification. LessonOutlineEntryLessonEntryKeeps id, kind, topic, theme; drops workingTitle and intent. lesson-files.spec enforces the match. LessonFileseedLessonsParsed with LessonFileSchema; bad files and duplicate ids fail by name. seedLessonsLessonAdds lang and level from the file, position from the array index. Upserts only changes. LessonBriefLesson.briefValidated by Zod on the way in, stored as untyped Json, never selected by the read routes. LESSON_KINDS, THEMESLessonKind, ThemeThe TypeScript lists in #77 mirror the Prisma enums in #79; kept in sync by hand. LESSONS_PER_LEVEL, KIND_COUNTSoutline-files.specEach outline must have exactly the level's count, and exactly its language's count for each kind: one table for French and German, one for English. Lesson + LessonResultLessonCardMapped to rule types in #80, then to a card; no result means status todo and nulls. LessonCardToday, LessonPageBoth views are containers of cards. LessonQueryLessonPageFilters, sort, group and page drive the in-memory search; total follows filters, levelTotal doesn't. User.timeZonedayThe course day (YYYY-MM-DD) is today in the learner's time zone; every day in Today, LessonPage and LessonResult uses it. UserLevel streak colsToday.streakstreak, bestStreak and lastGoalDay become current, best and today via currentStreak. FinishLessonLessonResult, UserLevelUpserts the result (best score kept) and may write the streak. LessonResult, UserLevelFinishResultcountedToday and doneCount come from that day's rows; goalJustMet is true only when this call wrote the streak.
