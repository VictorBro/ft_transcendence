Lessons data model

Every lesson format of the Course Roadmap and Lessons milestone, as replanned in #137, grouped by layer: the enums and constants, the shared contract, the lesson files of the prototype's model (#135), the checks and seed that guard the database, the Prisma models, the player domain and the views the browser may see (#144), the API schemas, the service types of the rule functions, and the helper types of single issues. Each card lists the issues that reference it, and has an anchor named after its type, so issues can link to it. References cover #76 to #153. Cards marked "to check" are derived from the issue text and still need confirming; "planned" cards are not on main yet. The schemas and validators of #135 are on main since PR #142, so their cards follow the code. Gone with the replan: LessonDraft, LessonBrief, VocabularyEntry, LessonDraftFile, the Gemini generator and, with #145, PUT …/result and LESSON_STUB.

Lesson files (JSON)outlines in #77lesson files in #135, on main since PR #142packages/shared/src/lessons
The authored source of truth, committed to git and read only by the seed. Outlines plan a level. A lesson is the prototype's model (schemaVersion 2): one brief per lesson for every kind, plus one content file for every kind but vocabulary, whose lesson is its brief. They are written offline with Claude Code (#83, #84, #91 to #93), never at runtime. The folder is exported from @ft/shared as the namespace lessons, never with export *.
