Social and real-time data model

Every format of the Real-time, social and defence milestone, grouped by layer: the enums and constants, the socket contract in packages/shared, the Prisma models, the presence state in Redis, the REST schemas, the web pieces that hold the connection, what the evaluation checks, and the modules. Each card lists the issues that reference it, and has an anchor named after its type, so issues can link to it. References cover #34 and #154 to #161. Almost everything here is planned: cards marked "existing" are on main and reused or changed, cards marked "to check" name a shape the issues describe without fixing its name or fields, so confirm them before implementing. One WebSocket connection per browser tab, in a user:<id> room; the lesson discussion of Milestone 2 streams over SSE, not over the socket.
